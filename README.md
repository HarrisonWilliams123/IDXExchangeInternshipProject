#California Residential Real Estate Analytics Pipeline 
#- IDXExchange Data Analyst Project

Market Intelligence Report: https://1drv.ms/w/c/a88d152ab49a4ee2/IQCU7SSb9BxYSr1wvKUd9G4gAfEOFF9bR1jstZv8OcBiF0s?e=F31gS8

This project is an end-to-end data pipeline. It takes 30 months of California MLS (CRMLS) data covering roughly 1.6 million listing and sold records from January 2024 to June 2026, and turns it into clean, analysis-ready datasets. Along the way it adds macroeconomic data, geospatial data and engineered market metrics.

The pipeline covers the full analyst workflow:
- Raw-data aggregation
- Exploratory data analysis
- External data enrichment (Federal Reserve mortgage rates)
- Data-quality validation
- Feature Engineering
- Spatial Joins (school districts)
- Statistical outlier treatment
